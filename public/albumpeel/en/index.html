Install & UseInstall and use at a glance

  • Requirements: Windows 10/11 64-bit only, about 100 MB installed, scans of 300 dpi or more recommended, input JPG · PNG · TIF · BMP.
  • Install: the installer asks for administrator rights (normal). Close the program before installing a new version; your settings and license record are kept.
  • Windows warning: the installer is not code-signed yet, so SmartScreen may warn. If you know where the file came from, choose More info → Run anyway.
  • Use: 1) open a scan 2) find photos 3) save. Drag corners to fix a box, draw a box in an empty area for a missed photo. Many pages: use Batch.
  • Your original scan is never changed. Box corrections are kept in a small file next to the scan.

FAQFrequently asked questions

A photo was not found. What now?

Drag in an empty area to draw a box and fit its four corners to the photo. If it happens often, leave a little more gap between photos when scanning.

Does it change my original scan?

No. Scan files are only read.

Do I need the internet?

Not for using it and not for activation.

What if I change my PC?

The license is for one PC and the PC cannot be changed. Only if the PC has failed, one recovery per license is possible. Details: Purchase & License.
